<h1 align="center">Taskit</h1>

<p align="center">할 일을 비스킷 조각처럼, 한 입씩 야금야금 해치우는 Windows 데스크톱 TODO 앱</p>

## Taskit이라는 이름

**Taskit**은 "Task"에 한 입 베어 문다는 뜻의 "-bite"를 붙인 말장난 이름입니다.
아이콘도 한 입 베어 문 비스킷 모양의 체크리스트로, 여기서 아이덴티티를 그대로 가져왔습니다.

할 일 목록을 한 번에 다 해치우려 하면 부담스럽지만, 비스킷을 오독오독 나눠 먹듯 **작게 쪼개서 하나씩** 처리하다 보면
어느새 목록이 비어 있다는 게 Taskit이 지향하는 사용 방식입니다. TODO/TBD로 자동 분류해 주는 것도,
체크박스 하나하나 지워 나가는 손맛도, 완료한 흔적을 이력으로 남겨 두는 것도 전부 그 방향을 돕기 위함입니다.

## 내려받아 쓰기

[릴리스 페이지](https://github.com/nwsugz/work_todo/releases)에서 `Taskit.exe`를 내려받아 바로 실행하면 됩니다. 설치 과정은 없습니다.

업무·규칙·설정 데이터는 `%APPDATA%\TodoTBD\` 폴더에 JSON으로 저장됩니다. 이 폴더를 통째로 복사해 두면 백업이 됩니다.

## 기본 사용법

### 보드 (TODO / TBD)

- **새 업무** 버튼(또는 `Ctrl+N`)으로 업무를 등록합니다. 제목, 카테고리, 시작일, 마감일, 메모를 넣을 수 있습니다.
- 등록된 업무는 아래 [자동 분류 규칙](#자동-분류-규칙)에 따라 **TODO**(지금 할 일) 또는 **TBD**(아직은 아닌 일) 칸에 자동으로 놓입니다.
- 카드 왼쪽 체크박스를 누르면 완료 처리되며 취소선이 그어집니다. 다시 누르면 완료가 취소됩니다.
- 카드를 더블클릭하면 편집, 오른쪽 클릭하면 편집·완료 처리·고정·삭제 메뉴가 뜹니다.
- 메모를 적어 두면 카드 제목 아래에 그대로 표시됩니다.

### 카드 옮기기 · 묶기

- 카드를 드래그해서 순서를 바꾸거나 TODO ↔ TBD 칸을 옮길 수 있습니다. 목록이 길어 화면 밖으로 넘쳐도 가장자리로
  끌고 가면 자동으로 스크롤됩니다.
- 한 카드를 다른 카드 위에 정확히 떨어뜨리면 그 카드의 **하위 업무**로 들어갑니다(한 단계까지). 상위 카드 왼쪽의
  화살표(▾/▸)를 눌러 하위 목록을 접었다 펼 수 있고, `하위 2/3`처럼 진행 상황이 표시됩니다.
- 다시 밖으로 꺼내고 싶으면 원하는 위치로 드래그해서 놓기만 하면 최상위 업무로 돌아옵니다.

### 완료 항목 보기

- 툴바의 **완료 항목 보기**를 누르면 지금까지 완료 처리한 모든 업무를 대주제-하위 업무 묶음 그대로 모아 보여줍니다.
  (다시 누르면 **TODO 목록**으로 돌아갑니다.)
- 완료한 카드는 TODO/TBD 화면에서 곧바로 지우기 전까지 두 화면 모두에서 계속 보입니다. TODO/TBD에서 카드를
  지우면 그 화면에서만 빠지고, 완료 항목 보기·업무 이력에서는 계속 확인할 수 있습니다.

### 업무 이력 (📅)

- 툴바의 달력 아이콘을 누르면 완료한 업무를 기간별로 훑어볼 수 있는 창이 뜹니다.
- 위쪽 월간 달력에는 각 대주제 업무가 시작일~마감일 구간의 색상 막대로 표시됩니다. 완료된 업무는 옅게,
  진행 중인 업무는 진하고 굵게 나와 한눈에 구분됩니다.
- 아래쪽에서 시작일·완료일을 직접 골라 그 기간에 완료한 업무만 트리 형태로 볼 수도 있습니다.
- 이 창은 TODO 보드를 가리지 않는 비모달 창이라, 열어 둔 채로 계속 업무를 추가·수정할 수 있고 그 내용이 바로 반영됩니다.

### 카테고리 우선순위

- 설정(⚙)에서 카테고리를 추가하고 드래그로 순서를 정할 수 있습니다. 목록 위쪽일수록 우선순위가 높아서,
  같은 칸 안에서 카테고리가 다른 업무들의 정렬 기준이 됩니다.

### 테마

- 설정에서 라이트/다크 모드를 고를 수 있습니다. 창 제목표시줄까지 함께 바뀝니다.

### 항상 위에 고정

- 툴바의 📌(또는 `Ctrl+T`)을 누르면 다른 창을 띄워도 Taskit 창이 뒤로 가지 않습니다. TODO 창에만 적용되고,
  설정·새 업무·업무 이력 같은 다른 창에는 영향을 주지 않습니다.

### 실행 취소

- `Ctrl+Z`로 방금 한 조작(추가·편집·삭제·완료 처리·고정·드래그 이동 등)을 최대 50단계까지 되돌릴 수 있습니다.

### 단축키

| 키 | 동작 |
| --- | --- |
| `Ctrl+N` | 새 업무 추가 |
| `Ctrl+Z` | 실행 취소 |
| `Ctrl+T` | 항상 위에 고정 켜기/끄기 |
| `F5` | 분류 규칙 다시 적용 |
| `Backspace` / `Delete` | 선택한 카드 삭제 |
| 더블클릭 | 업무 편집 |
| 오른쪽 클릭 | 편집 · 완료 처리 · 고정 · 삭제 메뉴 |

## 자동 분류 규칙

1. 업무를 새로 만들면 규칙을 위에서부터 훑어 **처음 걸린 규칙**이 TODO/TBD 칸을 정합니다.
2. 카드 아래 회색 글씨(마감일 옆)에 남은 기간이 함께 표시됩니다.
3. 카드를 직접 드래그해서 칸을 옮기면 그 순간 **고정**되어, 이후 규칙 재적용(F5) 대상에서 빠집니다.
   즉 규칙과 사람의 판단이 부딪히면 **사람이 이깁니다.**

규칙은 `%APPDATA%\TodoTBD\rules.json` 파일을 텍스트 편집기로 직접 고치고 앱에서 `F5`를 눌러 반영합니다.

```json
{
  "version": 1,
  "rules": [
    {
      "name": "보류 단어가 있으면 TBD",
      "when": { "title_contains": ["보류", "대기", "미정", "확인 필요"] },
      "then": "TBD"
    },
    {
      "name": "마감일이 14일 이내면 TODO",
      "when": { "due_within_days": 14 },
      "then": "TODO"
    },
    {
      "name": "그 밖에는 TODO",
      "when": {},
      "then": "TODO"
    }
  ]
}
```

규칙은 위에서부터 순서대로 평가하고 처음 걸린 것이 이깁니다. 한 규칙 안의 조건은 모두 만족해야 합니다.

| 조건 | 값 | 뜻 |
| --- | --- | --- |
| `title_contains` | 문자열 목록 | 제목에 이 단어 중 하나가 있으면 참 |
| `has_due` | `true` / `false` | 마감일이 있는지 |
| `due_within_days` | 정수 | 마감일이 오늘부터 N일 이내면 참 (이미 지난 것도 포함) |
| `overdue` | `true` / `false` | 마감일이 지났는지 |

`when`을 `{}`로 비워 두면 항상 참이므로 맨 마지막 기본 규칙으로 씁니다. 기본 규칙이 없으면 걸리는 규칙이 없는 업무는 TODO로 갑니다.

규칙 파일에 오타가 있으면 앱이 기본 규칙으로 되돌리고 알려 줍니다. 작업 내용이 날아가지는 않습니다.

## 소스에서 직접 실행

```bat
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python main.py
```

## 실행 파일 만들기

```bat
build.bat
```

`dist\Taskit.exe`가 생깁니다.

GitHub에 `v2.0.7` 같은 태그를 push하면 Actions가 자동으로 빌드해 릴리스에 `.exe`를 첨부합니다.

```bat
git tag v2.0.7
git push origin v2.0.7
```
