# TODO / TBD 보드

업무를 규칙에 따라 **TODO**(지금 손대는 일)와 **TBD**(아직 시작할 수 없는 일)로 자동으로 나눠 주는 Windows 데스크톱 앱입니다.
자동 분류가 마음에 들지 않으면 카드를 끌어다 놓으면 됩니다. 그 순간 그 카드는 **고정**되고, 이후 규칙은 그 카드를 건드리지 않습니다.

## 내려받아 쓰기

릴리스 페이지에서 `TodoTBD.exe`를 받아 실행하면 끝입니다. 설치 과정은 없습니다.
데이터는 `%APPDATA%\TodoTBD\` 아래에 저장됩니다.

| 파일 | 내용 |
| --- | --- |
| `tasks.json` | 업무 목록 |
| `rules.json` | 분류 규칙 |

## 자동 분류가 동작하는 방식

1. 업무를 새로 만들면 규칙을 위에서부터 훑어 **처음 걸린 규칙**이 칸을 정합니다.
2. 카드 아래쪽 회색 글씨에 어떤 규칙이 적용됐는지 그대로 나옵니다.
3. 카드를 다른 칸으로 끌면 `pinned` 표시가 붙고 왼쪽에 파란 막대가 생깁니다. 규칙 재적용에서 제외됩니다.
4. 고정을 풀려면 카드에서 오른쪽 클릭 → **고정 풀고 규칙에 맡기기**. 규칙이 다시 판단합니다.

즉 규칙과 사람의 판단이 부딪히면 **사람이 이깁니다.** 규칙은 아직 손대지 않은 카드만 정리합니다.

## 규칙 고치기

툴바의 **규칙 파일 열기**를 누르면 `rules.json`이 열립니다. 고친 뒤 **규칙 다시 적용**(F5)을 누르면 반영됩니다.

```json
{
  "version": 1,
  "rules": [
    {
      "name": "보류 단어가 있으면 TBD",
      "when": { "title_contains": ["보류", "대기", "미정", "확인 필요"] },
      "then": "TBD"
    },
    {
      "name": "마감일이 14일 이내면 TODO",
      "when": { "due_within_days": 14 },
      "then": "TODO"
    },
    {
      "name": "그 밖에는 TODO",
      "when": {},
      "then": "TODO"
    }
  ]
}
```

규칙은 **위에서부터 순서대로** 평가하고 처음 걸린 것이 이깁니다. 한 규칙 안의 조건은 모두 만족해야 합니다.

| 조건 | 값 | 뜻 |
| --- | --- | --- |
| `title_contains` | 문자열 목록 | 제목이나 메모에 이 단어 중 하나가 있으면 참 |
| `tag_any` | 문자열 목록 | 태그 중 하나라도 일치하면 참 |
| `has_due` | `true` / `false` | 마감일이 있는지 |
| `due_within_days` | 정수 | 마감일이 오늘부터 N일 이내면 참 (이미 지난 것도 포함) |
| `overdue` | `true` / `false` | 마감일이 지났는지 |

`when`을 `{}`로 비워 두면 항상 참이므로 맨 마지막 기본 규칙으로 씁니다. 기본 규칙이 없으면 걸리는 규칙이 없는 업무는 TODO로 갑니다.

규칙 파일에 오타가 있으면 앱이 기본 규칙으로 되돌리고 아래 상태 표시줄에 이유를 알려 줍니다. 작업 내용이 날아가지는 않습니다.

## 단축키

| 키 | 동작 |
| --- | --- |
| `Ctrl+N` | 새 업무 |
| `F5` | 규칙 다시 적용 |
| 더블클릭 | 업무 편집 |
| 오른쪽 클릭 | 편집 · 완료 · 고정 · 삭제 |

## 소스에서 직접 실행

```bat
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python main.py
```

## 실행 파일 만들기

```bat
build.bat
```

`dist\TodoTBD.exe`가 생깁니다.

GitHub에 올린 뒤 `v1.0.0` 같은 태그를 push하면 Actions가 자동으로 빌드해 릴리스에 `.exe`를 첨부합니다.

```bat
git tag v1.0.0
git push origin v1.0.0
```
